Build a complete, polished MVP web application called "Locora".

Locora is a hyperlocal discovery and request platform that connects customers with nearby local businesses.

The core idea is simple:

Businesses can tell nearby customers what they currently have, such as offers, discounts, new stock, restocked products, or services.

Customers can also tell nearby businesses what they are looking for.

The platform matches the two based on location, category, price and availability.

This is a hackathon MVP, so use realistic mock data and simulated functionality where a real backend would be unnecessary. However, the UI and interactions should feel like a real consumer application rather than a student demo.

TECH STACK
==================================================

- JavaScript

Use clean reusable React components and a sensible project structure.

The application must be easy to run and deploy on Replit.

==================================================
DESIGN DIRECTION
==================================================

The design should feel like a modern Indian consumer application.

Take general UX inspiration from apps such as Blinkit, Zepto, Swiggy and Zomato because Indian users are familiar with their interaction patterns.

DO NOT copy their branding, exact colors, layouts or visual identity.

Locora needs its own identity.

The app should feel:

- modern
- friendly
- visual
- clean
- practical
- slightly playful
- familiar to Indian users

Do NOT make it look like:

- a SaaS dashboard
- a college project
- an admin panel
- a generic Bootstrap website
- a fake phone mockup
- a futuristic AI interface

Avoid:

- gradients
- excessive glassmorphism
- excessive rounded cards
- excessive shadows
- excessive icons
- huge empty spaces
- walls of text

Use:

- strong typography
- clean spacing
- high-quality imagery
- vector illustrations
- attractive product cards
- offer banners
- subtle borders
- restrained shadows
- solid colors

Choose a distinctive Locora color palette yourself.

A warm coral/orange primary accent combined with dark navy text and light neutral backgrounds is one possible direction, but feel free to improve on it.

==================================================
RESPONSIVE LAYOUT
==================================================

IMPORTANT:

Do NOT create a fake 9:16 phone frame.

Do NOT center a tiny phone-shaped application on desktop.

The application should use the full browser viewport.

Design mobile-first, but make it responsive.

On mobile:

- compact header
- bottom navigation
- horizontally scrollable categories
- vertically stacked content
- touch-friendly controls

On desktop:

- use the available width intelligently
- create wider content sections

- maintain a polished consumer-app appearance

The same application should feel natural on both mobile and desktop.
